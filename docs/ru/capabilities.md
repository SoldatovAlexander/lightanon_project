# Границы возможностей

| Поверхность | Поддерживаемое поведение | Граница |
| --- | --- | --- |
| `Engine` с pandas | Пакетное обезличивание CSV/Parquet реализованными правилами | Ошибка правила очищает выходной столбец и фиксируется в аудите как ошибка. |
| `Engine` с Polars | Пакетная обработка CSV/Parquet правилами с `apply_polars` | Явная реализация для Polars есть у `Hash`; неподдерживаемые правила фиксируются как ошибки, а не пропускают данные. |
| `StreamEngine` | Низколатентная обработка событий-словарей | Каждое выбранное правило должно реализовывать streaming-операцию; перед production проверяйте точную схему. |
| RAG regex sanitizer | Обратимая токенизация включённых текстовых паттернов | Детектирование эвристическое. `coverage="heuristic"` и ноль совпадений не доказывают отсутствие ПД. |
| Metadata sanitizer | Рекурсивно обрабатывает строковые значения в dict/list/tuple/set | Без явной схемы не классифицирует числа, ключи словаря и произвольные атрибуты объектов. |
| `FileVault` | Локальное хранение обратимых токенов с шифрованием и блокировками v2 | Предназначен для небольших локальных задач. Для многопроцессного сервиса используйте транзакционную БД или Redis backend. |

Scope для восстановления RAG является доверенным серверным контекстом запроса. Он ограничивает одну операцию восстановления и не должен передаваться конечному пользователю как токен авторизации.
