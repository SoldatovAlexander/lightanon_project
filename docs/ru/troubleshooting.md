# Решение проблем

## `ImportError: pyarrow is required for parquet support`
Причина:
- отсутствуют зависимости для parquet.

Решение:
```bash
pip install -r requirements.txt
```

## Ошибка YAML-схемы
Причина:
- в YAML указано неизвестное правило, отсутствует `method`, переданы некорректные параметры или схема пуста.

Решение:
- проверить имя правила из документации и параметры конструктора; CLI не создаёт output при такой ошибке.

## Колонка стала пустой после обработки
Причина:
- правило завершилось с ошибкой;
- для fail-closed поведения LightAnon не оставляет исходные значения в выходном файле.

Решение:
- посмотреть `[FAIL]` в `engine.generate_report()`,
- исправить параметры правила или тип данных колонки,
- для `polars` добавить `apply_polars` в пользовательское правило, если оно отсутствует.

## Медленная обработка в `StreamEngine`
Причина:
- правило использует fallback в `apply_single`.

Решение:
- реализовать оптимизированный `apply_single` в используемых правилах.
